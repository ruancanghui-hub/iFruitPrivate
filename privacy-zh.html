水果风暴隐私政策

生效日期：2026 年 11 月 8 日
发布者：阮沧晖（Canghui Ruan）
隐私及支持联系方式：ruancanghui@163.com

本政策说明阮沧晖如何处理 iOS 游戏水果风暴（Fruit Storm，应用标识 com.nightelf.iFruit）中的信息，以及你联系支持或访问我们的政策和支持网页时涉及的信息。

游戏运行

水果风暴是一款单人消除游戏，无需注册账号即可游玩。游戏进度保存在设备上的应用存储空间，包括已解锁关卡、星级、分数、游戏内果汁、生命与恢复时间、道具数量，以及音乐和音效偏好。这些信息用于继续游戏和应用你的设置。

游戏读取设备的首选语言，以显示英文或简体中文；其他语言回落为英文。这一选择在设备上处理。

游戏没有账号登录，也不提供开发者运营的云存档服务。你启用的设备备份可能包含游戏数据，之后恢复备份时也可能恢复这些数据；这由你的 Apple 设备及账号设置管理。Apple 对 iCloud 云备份的说明

广告、支付与敏感权限

游戏未接入广告服务或真实货币应用内购买。补给使用游戏内果汁兑换。游戏玩法不需要读取通讯录、照片、定位、相机、麦克风或蓝牙。

分析、诊断与跟踪

水果风暴使用 Unity 游戏引擎运行。我们已为本游戏关闭 Unity 可选的分析、广告及云端崩溃和性能报告服务。我们不使用游戏活动建立广告画像，也不据此跨其他公司的 App 或网站跟踪你。

Apple 按照其自身服务及你的 Apple 设置处理 App Store 分发、设备备份，以及你选择共享的设备诊断信息。Apple 隐私政策

主动联系客服

如果你发送邮件至 ruancanghui@163.com，我们会收到你主动发送的信息，例如邮箱、消息及附件，并用于答复请求和处理相关支持问题。参与邮件传输和存储的邮箱服务也会处理这些邮件。请勿发送密码、付款资料或与问题无关的敏感信息。

我们在处理请求及相关问题所需的期间内保留支持邮件，或按适用法律要求保留。你可通过同一地址申请删除。我们不会出售支持邮件或将其用于个性化广告。

政策与支持网页

我们的政策和支持网页托管于 GitHub Pages。访问这些网页时，即使未登录 GitHub，GitHub 也会出于安全目的记录访客的 IP 地址。其网站信息处理方式见 GitHub Pages 数据收集说明 和 GitHub 隐私声明。

保留与用户选择

游戏保留本地进度及偏好，方便你继续游玩。音乐和音效可在游戏设置中调整。你可通过设备的“删除 App”操作移除应用本地数据；仅“卸载 App”以腾出空间可能保留数据。设备备份中的副本需在相应备份服务中另行管理，恢复备份也可能恢复存档。

我们无法远程删除仅保存在你的设备或由你控制的备份服务中的数据。对于你发给支持邮箱的信息，可通过 ruancanghui@163.com 申请访问、更正或删除，并适用该信息涉及的保留要求。

儿童

游戏不会要求玩家填写个人资料。如果你认为儿童向我们的支持邮箱发送了个人信息，请联系 ruancanghui@163.com，以便我们核实和处理。App Store 年龄分级以产品页面单独显示的结果为准。

政策变更与联系

信息处理方式发生变化时，我们会更新公开政策，并显示新的生效日期。
